# ACountryQuiz

An Android quiz app built in Java that tests your knowledge of countries.
Created as a class project to practice Android development.

## Features
- A quiz matching the country to the city
- Score Tracking
- Tracking previous records

## Built with
- Java
- Android SDK (Android Studio)

## Running it
1. Clone the repo
2. Open in Android Studio
3. Run on an emulator or a connected device

## What I learned
Building this was my hands-on intro to Android development — structuring
an app, handling user input, and managing state between screens.
